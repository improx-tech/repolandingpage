# repolandingpage

## RepoDesk Solutions — US Repossession Agency Back-Office Support

A premium, editorial-style B2B single-page landing page engineered for automotive repossession and recovery agencies across the United States. Built with Next.js 15, Tailwind CSS, TypeScript, and a unified warm parchment aesthetic inspired by high-end editorial publications.

### Features
- **100vh Hero Presentation**: Clean typographic focus, custom high-resolution fleet imagery, and direct operational desk routing (`+1 407 900 0208`).
- **Core Recovery Platforms**: Prominently featured workflows across RDN, Clearplan, Recovery Connect, I-Beam, ClearData, Wombat (ALS), IDI Core, and WebTransfer.
- **Operational Capabilities**: Distinct elevated shadow cards highlighting direct industry-focused experience, multi-platform handling, audit-ready documentation, and real-time field communication.
- **Zig-Zag Workflow Showcase**: Highlighting accepting/declining orders, status updates, condition reporting, skip tracing, and billing/invoicing.
- **Direct Dispatch & Demo Request Form**: Clean intake docket dispatching operational inquiries directly to `enquiry@improxgroup.com`.

### Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Standalone**: Standalone zero-dependency HTML mirror included (`index.html`)

### Getting Started

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
